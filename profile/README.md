## 💡 우리가 풀고 싶은 문제

지금 빈자리가 있는 버스도 내 정류장에 도착할 때는 만차일 수 있습니다. 버스가 이동하는 동안 승하차가 일어나기 때문입니다.

**만차예보**는 현재 잔여석과 과거 운행 사례를 활용해 **탑승 정류장에 도착할 때의 좌석 상태**를 예측하는 서비스를 목표로 합니다. 시민에게는 이동 선택의 근거를, 양주시와 운수사에는 혼잡과 좌석 여유를 파악할 정보를 제공하고자 합니다.

## ✨ 기획 중인 주요 기능

| 기능 | 제공하려는 정보 |
| :--- | :--- |
| 🧭 **경로 검색** | 출발지·도착지에 따른 대중교통 경로와 예상 도착 시각, 도보·환승 정보 |
| 🚌 **이번·다음 버스 비교** | 같은 노선·방향의 이번 버스와 다음 버스의 도착 시 만차 확률·예측 잔여석 |
| 🔎 **예측 근거 확인** | 유사 운행 사례, 최근 관측 시각, 데이터 부족·예측 보류 사유 |
| 🗺️ **지역 교통 대시보드** | 양주시 정류장·노선별 혼잡과 좌석 여유, 이용 가능한 대체 경로 |

## 🧠 예측은 이렇게 설계합니다

**경로·차량 확인 → 실시간 관측·유사 운행 검색 → 만차 확률·잔여석 예측 → 결과 검증**

- **만차 확률** — 현재 교통 상태와 유사한 과거 운행을 바탕으로 Jev가 도착 시 잔여석이 0석일 가능성을 추정합니다.
- **예측 잔여석** — 검색된 과거 사례의 실제 도착 잔여석 중앙값으로 대표 좌석 수를 계산합니다.
- **결과 검증** — 실행을 관리하는 하네스가 차량·정류장·기준시각과 데이터 최신성, 결과의 일관성을 확인합니다.

> 좌석 예측은 이동 판단을 돕는 정보입니다. 실제 탑승 여부는 정류장의 승하차와 대기 순서 등에 따라 달라지며, 근거가 부족한 경우에는 예측을 보류하도록 설계합니다.
